# \# Missão Espacial: Protocolo de Homologação em Camadas

# 

# Este projeto simula o fluxo de desenvolvimento de uma estação espacial utilizando diferentes ambientes de trabalho com Git e GitHub.

# 

# \## Camadas do ambiente

# 

# \### develop

# Ambiente de desenvolvimento.

# É onde são criadas e testadas novas funcionalidades.

# 

# \### stage

# Ambiente de homologação e testes.

# É onde as alterações são verificadas antes de irem para produção.

# 

# \### main

# Ambiente de produção.

# Contém a versão final e estável do projeto.
